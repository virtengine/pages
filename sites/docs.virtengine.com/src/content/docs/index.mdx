## About this documentation

This is the canonical documentation for the **VirtEngine Protocol** — the
CometBFT/Cosmos-SDK blockchain, its marketplace and identity systems, and the
operational tooling around them. VirtEngine is written in Go, licensed under
Apache 2.0, and implements methods protected by patent
[AU2024203136B2](https://patents.google.com/patent/AU2024203136B2/).

Documentation for the earlier managed cloud platform lives in the
[Cloud Platform (Legacy)](/cloud-platform/overview/) section.
